### 1. Data Collection

The first step in the project was collecting and importing the Vrinda Store sales dataset into Microsoft Excel.

#### What the Dataset Contained
The dataset included:
- Order details
- Customer information
- Product categories
- Sales amount
- Order status
- Sales channels
- Shipping details

#### Important Columns Used
- Order ID
- Customer ID
- Gender
- Age
- Date
- Status
- Channel
- Category
- Amount
- State

#### Purpose of Data Collection
The main goal was to gather all sales information in one place for:
- Sales analysis
- Customer behavior analysis
- Dashboard creation
- Business insights

#### What Was Done
- Opened dataset in Excel
- Verified all rows and columns
- Checked whether data was properly imported
- Ensured records were complete and readable

#### Benefit
This step helped prepare the data for creating the dashboard and doing sales analysis.
