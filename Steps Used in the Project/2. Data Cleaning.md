## 2. Data Cleaning

Data cleaning was done to make the dataset accurate, organized, and ready for analysis.

### What Was Done
- Checked for blank/null values
- Removed duplicate records
- Corrected inconsistent values
- Verified data types
- Standardized text values

### Features Used

Used Excel Filter option:

```text
Data → Filter

Used Find & Replace:

Ctrl + F → Replace
Examples
M → Men
W → Women
One → 1
Two → 2

### Purpose

This step helped make the data clean and reliable for creating PivotTables, charts, and dashboard analysis.
