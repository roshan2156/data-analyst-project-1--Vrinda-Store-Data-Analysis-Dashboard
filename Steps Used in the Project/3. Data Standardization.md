+ ## 3. Data Standardization
+ 
+ Data standardization was performed to make the dataset consistent and uniform for accurate analysis.
+ 
+ ### Problem Identified
+ 
+ Some values in the dataset were inconsistent.
+ 
+ #### Gender Column Issues
+ Different formats were used for the same values:
+ - Men
+ - M
+ - Women
+ - W
+ 
+ This created inconsistency in the dataset.
+ 
+ #### Quantity Column Issues
+ Quantity values were stored in different formats:
+ - One
+ - 1
+ - Two
+ - 2
+ 
+ This caused problems during analysis and PivotTable creation.
+ 
+ ---
+ 
+ ### Steps Performed
+ 
+ #### Standardizing Gender Column
+ 
+ 1. Clicked on the filter dropdown button in the Gender column.
+ 2. Unselected all checkboxes.
+ 3. Selected only:
+    ```text
+    M
+    ```
+ Clicked OK.
+ 
+ Used:
+ 
+ Ctrl + F → Replace
+ 
+ Replaced:
+ 
+ M → Men
+ 
+ Clicked:
+ 
+ Replace All
+ 
+ Repeated the same process for:
+ 
+ W → Women
+ 
+ After replacement:
+ 
+ Selected all checkbox values again from filter dropdown.
+ Standardizing Quantity Column
+ 
+ Some quantity values were written as text while others were numeric.
+ 
+ Examples:
+ 
+ One
+ Two
+ 1
+ 2
+ 
+ Used Find & Replace to standardize values:
+ 
+ One → 1
+ Two → 2
+ Purpose
+ 
+ This step helped:
+ 
+ Maintain consistency in the dataset
+ Improve PivotTable accuracy
+ Prevent duplicate category creation
+ Ensure proper dashboard analysis
+ Benefit
+ 
+ After standardization:
+ 
+ Data became clean and organized
+ Analysis became more accurate
+ Charts and PivotTables worked correctly
